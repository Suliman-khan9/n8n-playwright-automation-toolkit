# Contributing

Thanks for considering a contribution. Please open an issue describing the bug or feature first if the change is substantial.

1. Install Node.js 20 or later.
2. Run `npm test` and `npm run lint` before submitting a pull request.
3. Add regression tests for bug fixes.
4. Keep health checks read-only and avoid dependencies unless they have a documented benefit.
5. Never upload API keys, private URLs, browser profile directories, cookies, tokens, or production workflow exports.

When reporting bugs, include the Node.js version, a sanitized command, observed output and expected output. Replace hostnames or repository details if sensitive.
